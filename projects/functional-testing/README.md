# 🧪 Functional Testing Project

## 📌 Descripción

Proyecto de demostración de pruebas funcionales aplicado a una
aplicación web de comercio electrónico.

El objetivo es mostrar el proceso de QA desde el análisis de
requerimientos hasta la ejecución de pruebas, identificación de
defectos y validación de resultados.

---

## 🎯 Objetivo

Validar que las principales funcionalidades de la aplicación
cumplan con los requerimientos funcionales y proporcionen un
comportamiento esperado para el usuario.

---

## 🔎 Alcance

Las pruebas estarán enfocadas en:

- 🔐 Login
- 👤 Registro de usuario
- 🔎 Búsqueda de productos
- 🛒 Carrito de compras
- 💳 Checkout
- 📦 Confirmación de pedido
- 🚪 Logout

---

## 🧪 Tipos de pruebas

- Functional Testing
- Smoke Testing
- Regression Testing
- Negative Testing
- Exploratory Testing
- End-to-End Testing

---

## 🔄 Proceso de pruebas


```text
Requerimientos
      ↓
Análisis
      ↓
Diseño de escenarios
      ↓
Diseño de casos de prueba
      ↓
Preparación de datos
      ↓
Ejecución
      ↓
Reporte de defectos
      ↓
Retesting
      ↓
Regression Testing
      ↓
Cierre



| Artefacto   | Descripción                          |
| ----------- | ------------------------------------ |
| Test Plan   | Estrategia y alcance de las pruebas  |
| Test Cases  | Casos de prueba funcionales          |
| Bug Reports | Registro y seguimiento de defectos   |
| Test Data   | Datos utilizados durante las pruebas |
| Evidence    | Evidencias de ejecución              |


🛠️ Herramientas
GitHub

Navegador web

📊 Resultados

Los resultados de las pruebas serán documentados mediante
casos de prueba, evidencias y reportes de defectos.
